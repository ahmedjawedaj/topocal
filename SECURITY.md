# Security Policy

TopoCal is pre-alpha research software and should not be treated as a safety-certified engineering control.

For security vulnerabilities in the software itself, use
[GitHub private vulnerability reporting](https://github.com/ahmedjawedaj/topocal/security/advisories/new).
Include affected versions, a minimal reproduction, impact, and any suggested mitigation.
Avoid sharing secrets or private datasets. There is no guaranteed response time.

Do not report ordinary model-quality failures as software security vulnerabilities. Research failures should be filed using the research-result/bug templates with reproducible inputs.

Only the current pre-alpha development line is maintained. Use a current checkout;
there are no supported production releases or backport guarantees yet.
